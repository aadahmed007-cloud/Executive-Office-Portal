# مساعد مكتب رئيس مجلس الإدارة (Chairman's Office Assistant)

> **الحالة الفنية للمشروع:**  
> **1.0.0 Release Candidate (pending independent security review and IT approval).**  
> هذا المشروع لم يخضع بعد لمراجعة أمنية مستقلة أو اختبار اختراق معتمد، ولا يدعم حالياً المصادقة الثنائية (2FA). جميع البيانات المستخدمة وهمية تماماً.

---

## 1. الغرض من المشروع (Purpose)
نموذج أولي لواجهة مستخدم مصممة باللغة العربية أولاً (Arabic-First RTL) تهدف لمحاكاة واختبار الاحتياجات اليومية لمكتب رئيس مجلس الإدارة والسكرتارية التنفيذية، وتغطي:
- مفكرة المواعيد والاجتماعات وجداول الأعمال وتدوين المحاضر.
- سجل الوارد والصادر ومذكرات العرض والتأشيرات الرئاسية.
- التكليفات الرئاسية ومتابعة نسب الإنجاز وتقارير المتابعة الدورية.
- سجل الرقابة والمراجعة للأحداث التشغيلية الحساسة (سجل يكشف التلاعب).
- الملخص الأسبوعي والإحصائي.

---

## 2. الهندسة المعمارية (Architecture Summary)
- **الواجهة:** React 19 + TypeScript + Tailwind CSS (SPA خالي من المنطق الحساس).
- **الخادم الخلفي:** Node.js Express API مع محرك SQLite حقيقي (`better-sqlite3`) ونمط WAL.
- **تخزين البيانات:** تعتمد المنظومة على قاعدة بيانات SQLite مشغلة على الخادم (Server-side) لضمان اتساق البيانات ومركزيتها.
- **نمط المستودعات (Repository Pattern):** واجهات برمجية صارمة (`src/data/contracts/index.ts`) تفصل طبقة العرض عن محرك التخزين بالكامل.
- **النسخ الاحتياطي المشفر:** تشفير AES-256-GCM واشتقاق scrypt وتحقق فوري تلقائي (`npm run backup`).
- **التدويل (i18n):** ملف نصوص مركزي (`src/i18n/ar.json`) دون أي نصوص ثابتة مبعثرة.
- **عمل بدون اتصال (Offline):** خلو تام من أي نصوص CDN أو خطوط خارجية عبر الإنترنت.

## 3. أنماط النشر المعتمدة والحدود التقنية (Supported Deployment Modes & Limitations)

### الأنماط المدعومة حالياً (Currently Supported Modes):
1. **النمط الأول (مدعوم رسمياً):** شبكة محلية مخصصة داخل مكتب الرئيس مع خادم احتياطي دافئ (`On-premise LAN + warm standby`).
2. **النمط الثاني (مدعوم بموافقة كتابية):** شبكة محلية مع نفق VPN معتمد للوصول عن بُعد (`On-premise + approved VPN for remote access`).

> ⚠️ **تحذير هام بشأن بيئة المعاينة السحابية (Cloud Run / Google AI Studio Publish):**  
> نشر التطبيق عبر خاصية "Publish" أو على Google Cloud Run مخصص **حصرياً للعرض التوضيحي باستخدام بيانات وهمية تماماً (Demos with fictional data only)**؛ نظراً لأن أقراص التخزين هناك مؤقتة (Ephemeral Disk) والعنوان متاح على الإنترنت العام دون نفق معتمد.

### الحدود المعروفة (Known Limitations):
1. **المراجعة الأمنية المستقلة:** لم يخضع النظام بعد لمراجعة أمنية خارجية مستقلة أو اختبار اختراق معتمد (the system has had no independent security review).
2. **المصادقة الثنائية (2FA):** لا يدعم النظام حالياً المصادقة الثنائية (2FA)، ويشترط استيفاء قرار بشأنها قبل أي إتاحة عن بُعد.
3. **تحديث البيانات والتزامن:** استطلاع دوري عبر Page Visibility API بفارق نحو 20 ثانية، وقاعدة "الحفظ الأخير يربح" (last-save-wins) عند التعديل المتزامن.
4. **محرك قاعدة البيانات:** كاتب أحادي (Single-Writer SQLite) بنمط WAL، ويحظر وضع ملف قاعدة البيانات على مشاركات شبكية (SMB/NFS).
5. **سجل الرقابة:** محفزات SQLite وسلسلة التجزئة التشفيرية توفر سجلاً يكشف التلاعب (tamper-evident).

للمزيد من التفاصيل، يرجى مراجعة [سجل قرارات النشر (docs/DEPLOYMENT_DECISION_AR.md)](./docs/DEPLOYMENT_DECISION_AR.md).

## 4. التشغيل المحلي والاختبارات (How to Run & Test)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة العمل المحلية
npm run dev

# تشغيل حزمة الاختبارات الآلية (7 أجنحة اختبار مؤمنة)
npm test

# فحص الأنماط والأنواع البرمجية
npm run lint

# بناء نسخة الإنتاج
npm run build
```
